# codex-cartoon

**Especialista em arte cartoon/toon** do codex-studio. Especialização de **estilo** sobre o `codex-sprite`: herda o fluxo game dev e injeta o bloco de estilo cartoon — cores vibrantes chapadas, contorno grosso limpo, formas arredondadas exageradas, leitura alta (vetor/mobile game).

## Skill

- **`codex-cartoon:cartoon`** — assets cartoon game-ready. Pós = remoção de fundo pra alpha; **mantém** as bordas suaves (não pixeliza).

## Requisitos

- `codex-sprite` instalado (fluxo base + script `spritekit.py`).
- `codex-image` (motor keyless).
- `pip install Pillow`.
