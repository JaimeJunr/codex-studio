# codex-infographic

Transforma número/dado/métrica em **imagem infográfica** on-brand via Codex (keyless): big number, comparativo, timeline, funil, antes/depois.

## Skill
- **`codex-infographic:infographic`** — dado vira visual. O número exato entra como texto; o resto é ilustração.

## Honestidade
Modelo de imagem não faz gráfico proporcionalmente exato. Pra série temporal/distribuição precisa, gere o gráfico real (lib de chart) — a skill avisa quando esse é o caso.

## Requisito
`codex-image` instalado.
