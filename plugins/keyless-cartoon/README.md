# keyless-cartoon

**Especialista em arte cartoon/toon** do keyless-studio. Especialização de **estilo** sobre o `keyless-sprite`: herda o fluxo game dev e injeta o bloco de estilo cartoon — cores vibrantes chapadas, contorno grosso limpo, formas arredondadas exageradas, leitura alta (vetor/mobile game).

## Skill

- **`keyless-cartoon:cartoon`** — assets cartoon game-ready. Pós = remoção de fundo pra alpha; **mantém** as bordas suaves (não pixeliza).

## Requisitos

- `keyless-sprite` instalado (fluxo base + script `spritekit.py`).
- `keyless-image` (motor keyless).
- `pip install Pillow`.
