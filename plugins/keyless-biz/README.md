# keyless-biz

Especialista **negócio** sobre o `keyless-deck`: templates prontos de **pitch deck, deck de vendas, proposta comercial e QBR/relatório executivo**.

## Skill
- **`keyless-biz:biz-deck`** — sequência de slides + ângulo de cada um por formato; delega geração/montagem ao `keyless-deck`.

## Requisito
`keyless-deck` + `keyless-image` instalados.
