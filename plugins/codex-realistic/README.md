# codex-realistic

**Especialista em arte realista/painterly** do codex-studio. Especialização de **estilo** sobre o `codex-sprite`: herda o fluxo game dev e injeta o bloco de estilo semi-realista — volume, iluminação direcional, texturas detalhadas, shading rico (RPG/estratégia, ícones detalhados, key art, retratos).

## Skill

- **`codex-realistic:realistic`** — assets painterly game-ready. Pós = remoção de fundo pra alpha; **não** pixeliza nem impõe paleta.

## Requisitos

- `codex-sprite` instalado (fluxo base + script `spritekit.py`).
- `codex-image` (motor keyless).
- `pip install Pillow`.
