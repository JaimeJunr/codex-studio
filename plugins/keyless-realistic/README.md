# keyless-realistic

**Especialista em arte realista/painterly** do keyless-studio. Especialização de **estilo** sobre o `keyless-sprite`: herda o fluxo game dev e injeta o bloco de estilo semi-realista — volume, iluminação direcional, texturas detalhadas, shading rico (RPG/estratégia, ícones detalhados, key art, retratos).

## Skill

- **`keyless-realistic:realistic`** — assets painterly game-ready. Pós = remoção de fundo pra alpha; **não** pixeliza nem impõe paleta.

## Requisitos

- `keyless-sprite` instalado (fluxo base + script `spritekit.py`).
- `keyless-image` (motor keyless).
- `pip install Pillow`.
