# codex-study

Especialista **estudo** sobre o `codex-deck`: **deck de aula, resumo visual, flashcards em imagem e defesa/apresentação acadêmica**.

## Skill
- **`codex-study:study-deck`** — estrutura pedagógica (objetivo → conteúdo → checagem); delega geração/montagem ao `codex-deck`. Em defesa, insere as figuras reais do trabalho.

## Requisito
`codex-deck` + `codex-image` instalados.
